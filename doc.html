Implementace

  • project/models.py - definice datových modelů pro celý systém, jelikož všechny operace vyžadují práci daty
    • Administrátor - modely uživatelů k vytvoření a správě účtů pro pečovatele a veterináře
    • Pečovatel - modely zvířat, pro přidávání nových záznamů o zvířatech, vedení jejich historie a správa rozvrhů pro venčení
    • Veterinář - modely pro zdravotní záznamy a plánování vyšetření.
    • Dobrovolník - modely rezervace venčení
  • project/views.py - logika pro zpracování požadavků uživatelů
    • Administrátor - správa uživatelů (vytváření, editace, mazání)
    • Pečovatel - přidávání, úprava a mazání záznamů o zvířatech, správa rozvrhů venčení, schvalování rezervací a ověřování dobrovolníků
    • Veterinář - správa zdravotních záznamů a vyřizování požadavků na vyšetření od pečovatelů
    • Dobrovolník - rezervace zvířat na venčení a zobrazení historie svých minulých venčení
  • project/urls.py - zajišťuje mapování URL adres na jednotlivé funkce ve views.py
  • project/forms.py - definice formulářů pro zadávání nebo úpravu dat jednotlivými uživateli
  • project/logout.py - zajišťuje automatické odhlášení nečinného uživatele po uplynutí 5 minut
  • project/backends.py - obsahuje vlastní implementaci autentizační logiky
  • project/templates - tato složka obsahuje HTML šablony, které zobrazují data uživatelům

Databáze

Implementováno pomocí MySQL v dbinit.sql

Instalace

Postup instalace na server

  1. Stažení a rozbalení archivu (zip souboru s projektem)
  2. Vytvoření virtuálního prostředí pomocí python -m venv NAME
  3. Aktivace virtuálního prostředí:
    • Na Windows:NAME\Scripts\activate
    • NaWSL/Linux:source NAME/bin/activate
  4. Pokud používáte WSL/Linux, je před instalací závislostí třeba nainstalovat MySQL klientskou knihovnu sudo apt install default-libmysqlclient-dev build-essential
  5. Instalace závislostí pomocí příkazu pip install -r requirements.txt
  6. Spuštění serveru pomocí:python manage.py runserver
  7. Otevřete prohlížeč a navštivte adresuhttp://127.0.0.1:8000/

Softwarové požadavky

  • Python: Verze 3.12.5
  • Django: Verze 5.1.1
  • MySQL: Verze 8.0
  • Pro další požadavky viz. requirements.txt

Postup konfigurace databáze

Databáze je hostována na externí platformě Aiven, přičemž systém se k ní pouze připojuje. Pro opětovnou inicializaci databáze stačí v kořenovém adresáři spustit příkaz:

python manage.py migrate

Tímto způsobem se databáze naplní výchozími inicializačními daty.
