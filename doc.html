Implementace

  • project/models.py - definice datových modelů pro celý systém, jelikož všechny operace vyžadují práci daty
    • Administrátor - modely uživatelů k vytvoření a správě účtů pro pečovatele a veterináře
    • Pečovatel - modely zvířat, pro přidávání nových záznamů o zvířatech, vedení jejich historie a správa rozvrhů pro venčení
    • Veterinář - modely pro zdravotní záznamy a plánování vyšetření.
    • Dobrovolník - modely rezervace venčení
  • project/views.py - logika pro zpracování požadavků uživatelů
    • Administrátor - správa uživatelů (vytváření, editace, mazání)
    • Pečovatel - přidávání, úprava a mazání záznamů o zvířatech, správa rozvrhů venčení, schvalování rezervací a ověřování dobrovolníků
    • Veterinář - správa zdravotních záznamů a vyřizování požadavků na vyšetření od pečovatelů
    • Dobrovolník - rezervace zvířat na venčení a zobrazení historie svých minulých venčení
  • project/urls.py - zajišťuje mapování URL adres na jednotlivé funkce ve views.py
  • project/forms.py - definice formulářů pro zadávání nebo úpravu dat jednotlivými uživateli
  • project/templates - tato složka obsahuje HTML šablony, které zobrazují data uživatelům

Spuštění projektu lokálně

  1. Stažení a instalace Pythonu: Python 3.12.5
  2. Instalace závislostí: přesuňte se do složky projektu nainstalujte závislosti: pip install -r requirements.txt
  3. Spuštění serveru: server spustíte příkazem: python manage.py runserver
  4. Ověření funkčnosti: otevřete prohlížeč a navštivte adresu http://127.0.0.1:8000/
